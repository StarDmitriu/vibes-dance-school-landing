# Vibes Dance School Landing

Concept marketing page for a dance school: directions, teachers, schedule, pricing, reviews, and signup.

Demo concept — not an official school website.

## Sections

- Directions / how to choose
- Teachers
- Schedule & pricing
- Reviews & contacts
- Signup CTA

## Stack

- HTML / CSS / JavaScript

## Run locally

Open `index.html`, or:

```bash
npx serve .
```
